# Changelog

## 0.4.0 — 2026-10-30

Foreground watch with native events, debounce/stable-file checks, retries and periodic/startup hash reconciliation; read-only revision listings and block/note diffs; conservative rename recovery; schema 2 transition events with pre-migration backup; retained canonical snapshots and documented retention.

## 0.3.0 — 2026-10-30

Phase 3: transactional SQLite schema 1, persistent document/revision identity, incremental recursive ingestion, FTS5 cross-chapter and note search, full passage/note retrieval, indexed exports, per-retrieval freshness, retained good revisions on failure, source reconciliation and private permissions. Configured corpus indexed with explicit partial-failure reporting.

## 0.2.1 — 2026-10-30

Assistant-performed 20-page Word review; preserve direct editorial formatting and repeated note-body self-markers; suppress false numbering warning for numId=0; deterministic Markdown metadata; 37 passing tests.

## 0.2.0 — 2026-10-30

Phase 2: read-only OOXML extraction, footnote/endnote anchor validation, heading/table order, image metadata, saved fields and hyperlinks, explicit unsupported-content handling, deterministic UTF-8 JSON/Markdown with source hashes, private export publication, synthetic/golden/failure tests and an authorized real-chapter XML audit. Human Word fidelity acceptance remains pending.

## 0.1.0 — 2026-10-30

Phase 1: Python packaging and CLI entry point; non-overwriting setup; versioned TOML configuration and discovery; read-only doctor with FTS5 check; JSON output; stderr-only logging; privacy exclusions; synthetic tests and pinned developer tools; installation/PATH and operational documentation.

Phase 0: requirements, Word feature matrix, architecture, conceptual data model, privacy decisions and staged acceptance plan. User authorized Phase 1 after design refinements.

## Phase 5 workflow (CLI unchanged at 0.4.0)

Added evidence-based query instructions, a 20-question candidate benchmark, and a read-only provenance audit script. Real manuscript trial evidence is private. Human curation and interpretive acceptance remain pending; no AI endpoint or MCP service was added.

## 0.6.0 — Phase 6

Added explicit local analysis import/list/show/review, strict passage provenance, typed assertions and linked maps, dynamic dependency freshness, historical baselines, immutable analysis records and review history. Added change-impact candidate reports with lexical ranking and coverage limits. No model API, automatic inference, or DOCX editing.

## 0.7.0 — Reliability and academic handover

Added verified backup/check/restore commands, preserving active data during recovery and coordinating writers across index/analysis snapshots. Added setup --codex with book-specific instructions, non-overwriting startup-file generation and a local installer. Corrected missing-source messaging when no successful revision exists. Rewrote the user guide around academic tasks and moved installation/maintenance to a separate guide. Regression, clean-install, real-corpus recovery and accelerated editing checks pass. Multi-day author acceptance and v1.0 sign-off remain pending.
